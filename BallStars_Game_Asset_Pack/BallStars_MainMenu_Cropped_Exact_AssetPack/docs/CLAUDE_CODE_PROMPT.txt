PRIMARY CARD STACK
You are NOT redrawing the cards from scratch.
Use the provided base images.

For each of the three main actions:
1. Create a Box with a fixed width relative to screen (~84–88% width).
2. Put the card-base image as the background of that Box.
3. Overlay the exact icon crop on the left.
4. Overlay native Compose text on top.
5. Make the whole card clickable.

Suggested proportions:
- card visual width: 84–88% of screen width
- card visual height: auto from aspect ratio of supplied image
- gap between cards: ~10–14.dp

Because the icons are already exact crops, place them near the left edge of the card with padding.

- title left offset begins just after icon block
- title bold white, uppercase
- subtitle pale blue/grey
- vertically centre the content

Do NOT place text too low.
Do NOT leave the huge dead space seen in the broken version.
