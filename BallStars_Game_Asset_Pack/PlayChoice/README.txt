BallStars — Play Choice Asset Pack

Purpose:
A portrait-phone choice screen asking whether the player wants to:
- follow Setup Steps
- go directly to Training Sessions
- go directly to Matches

IMPORTANT:
The generated concept board is intentionally included only as a visual reference.
Its three-column layout is too wide for a modern phone.

The Compose implementation should use:
- boy + girl hero at the top
- native heading/subheading
- three full-width choices STACKED vertically
