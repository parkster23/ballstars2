BallStars — Target Detection / Set Up The Zone

Asset pack for reskinning the existing ScanTargets2Screen manual calibration screen.

The BallStars artwork creates an ~8–10% frame around a large central REAL CameraX viewport. Native Compose overlays provide the nine touch-calibration steps, zoom, instructions, Reset/Confirm and confirmed Nexus Grid.

The existing Kotlin implementation is the source of truth for behaviour. Do not replace it with OpenCV/TFLite/automatic detection.
