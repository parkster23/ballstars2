ROOT STRUCTURE
Use a portrait BoxWithConstraints:

BoxWithConstraints(
    modifier = modifier
        .fillMaxSize()
        .background(Color(0xFF07131F))
) {
    // decorative artwork
    // safe-area content
}

Decorative artwork must never determine click geometry.

Suggested z-order:
1. deep navy base
2. urban/graffiti decorative images
3. optional dark readability gradient
4. logo/header
5. native Compose menu cards
6. Stats / Settings

SAFE AREAS
Use statusBarsPadding() and navigationBarsPadding().
Target Pixel 9 portrait, but adapt to smaller Android portrait screens.

Do NOT use fixed pixel coordinates from the reference image.
Use dp, constraints and proportional sizing.

HEADER
Recreate the top of the reference:
- BallStars logo centered/prominent
- urban skyline/graffiti behind it
- compact enough to leave room for all cards

If a clean BallStars logo resource already exists, use it with ContentScale.Fit.
Never crop or stretch the logo.

PRIMARY CARD STACK
Cards are vertically stacked with small consistent gaps.

Recommended:
horizontal padding: 16–20.dp
card height: responsive, normally ~76–88.dp
corner radius: ~20–24.dp
internal horizontal padding: ~16.dp

Card structure:
[icon] [heading + subtitle] [optional subtle chevron]

Whole card is clickable.

TRAINING

Heading: TRAINING
Subtitle: Practice patterns
Callback: onTraining()

GAME MODE

Callback: onGameMode()

SETUP ZONE

Heading: SETUP ZONE
Subtitle: Calibrate your grid
Callback: onSetupZone()

CARD VISUAL STYLE
- dark navy interior
- bright coloured outline
- subtle outer neon glow
- bold white heading
- pale secondary subtitle
- icon on left
- maintain high contrast
- avoid excessive glow that reduces legibility

If Compose shadow/glow implementation becomes platform-specific, prioritize:
1. correct border
2. correct dark card fill
3. spacing
4. typography
over complicated effects.

BOTTOM ACTIONS
Below the three cards, create a Row:
Stats                              Settings

Each action is icon above label or icon+label according to available height.
Callbacks:
Stats -> onStats()
Settings -> onSettings()

These are compact actions, NOT additional large cards.

RESPONSIVE VERTICAL LOGIC
This reference is intentionally narrow/mobile portrait.

Use available maxHeight to tune:
- header height
- gaps
- card height

On shorter phones reduce in this order:
1. header artwork height
2. spaces between cards
3. card vertical padding/card height
4. bottom-section spacing

Never:
- crop the logo
- hide a menu option
- reduce clickable height below 48.dp
- turn the design into a scrolling wide/tablet layout merely to make it fit

A LazyColumn is unnecessary on normal phone sizes. Only introduce scrolling as a defensive fallback for very short accessibility/font-scale layouts.

TYPOGRAPHY
Use the project's existing BallStars display font for headings if available.
Do not add/download a new font.
Headings should visually resemble the chunky white headings in the reference.
Subtitles should be simpler and lighter.

CARD IMPLEMENTATION

Do not use the card-reference PNG as the clickable card.

Instead construct the card in Compose:

Box(
    modifier = Modifier
        .fillMaxWidth()
        .height(...)
        .border(...)
        .background(...)
        .clickable { ... }
) {
    Row {
        Image(icon)
        Column {
            Text(title)
            Text(subtitle)
        }
    }
}

This allows the cards to scale correctly between different
portrait Android devices.


IMPORTANT: IMAGE SIZING

For all decorative artwork:

preserve aspect ratio.

for logo/icons and:

where the environmental background needs to bleed.
