VERTICAL COMPOSITION

Target portrait phone / Pixel 9.

Header/logo area:
~18–23% of usable height.

Primary card block:
Immediately below logo.
Three cards should form a compact stack occupying roughly the next 38–44%.

Stats/Settings:
Immediately below the card block with a modest gap.
Do NOT push them to the very bottom using Spacer(weight = 1f).

Allow remaining lower background artwork to breathe naturally.

Recommended:
logo bottom -> first card: 12–20.dp
card gap: 10–14.dp
Setup Zone -> Stats/Settings: 20–30.dp
