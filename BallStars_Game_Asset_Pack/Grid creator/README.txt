BallStars — Grid creator Asset Pack

Explainer purpose:
Show users how to create visible real-world guides for BallStars' virtual scoring grid.

The user's real-world example used masking tape on a green mat. The app should not imply
that a special mat is required. Tape indoors, chalk outdoors, or other clearly visible
temporary guides can be used.

Pack includes:
- complete visual reference
- hero artwork
- separated player and phone/detection artwork
- tape, chalk and alternative grid examples
- heading/step assets
- three supporting icons
- optional ball/background/effect assets
- CLAUDE_CODE_PROMPT.txt for Compose Multiplatform implementation

Essential explanatory text and captions should be native Compose UI.
