CLAUDE CODE PROMPT — BALLSTARS EXPLAINER: GRID CREATOR

Implement ONE new-user explainer screen in the existing BallStars Kotlin Multiplatform / Compose Multiplatform application.

SCREEN
“Create Your Grid” / Grid Creator.

This screen follows the SAME theme, responsive dimension logic, component structure and visual hierarchy as the existing `SetupStartExplainerScreen`.

Before coding, inspect the existing Setup explainer implementation and REUSE its:
- scaffold/layout approach
- spacing/dimension logic
- typography
- colours
- safe-area handling
- feature-icon component
- Next CTA
- onboarding navigation/pager conventions

Do not create a parallel design system.

PURPOSE
Teach the user that BallStars needs visible physical guides on the floor so the camera can establish the virtual scoring grid.

The physical grid is only a guide. It does NOT need to be a special BallStars mat.

Users can create it using suitable visible markers such as:
- masking tape indoors
- chalk outdoors
- other clear temporary markings/markers that make the grid positions visible

The supplied real-world reference showed masking tape on a green mat. The explainer artwork generalises that concept.

IMPORTANT CONCEPT
The physical markings help the user and camera establish where the virtual grid/scoring zones are. BallStars then detects the nine target/scoring positions.

Do not imply that users must own a special mat.
